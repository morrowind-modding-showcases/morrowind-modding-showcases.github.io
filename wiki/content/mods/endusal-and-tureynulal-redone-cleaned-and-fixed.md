This is a bugfixed and clean version of both ESPs from the original mod. Here are all the fixes included : 

- Fixed the ESP name that wasn't right for some reason...
- Old cells from previous versions of Endusal and Tureynulal have been removed and their creature spawns aswell. 
- Missing textures that weren't included in the original download have been added. (And yes Greater Dwemer Ruins ESM file is still needed for assets)
- Dwemer Shaft Wall textures
- Missing BookArts 
- Missing Lava Textures
- The endless pit with no bottom in Endusal has been patched with lava so you can't fall out of bounds anymore.
- Cleaned both ESP files with tes3cmd
- Fixed multiple light sources that were misplaced / misaligned
- Fixed dwemer barrels clipping in each other
- Fixed crystals clipping through clutter
- Removed one creature spawn because it was in the void

## World Edits:

Overhauls the interiors of Endusal and Tureynulal. Adds one reference to an exterior cell on Red Mountain.

Makes NO landscape edits!
