Asset Repositories: Description:
OAAB Data (Website)
Interiors Exteriors 3D 2D Compatibility
Of Ash and Blight, an asset repository expanding a standardized set of resources for use with Morrowind and specifically Vvardenfell environments and locations. Some overlap with Tamriel Data.
Tamriel Data
Interiors Exteriors 3D 2D Compatibility
Asset repository featuring a standardized set of resources for use across the Tamriel Rebuilt and Project Tamriel provinces. Some overlap with OAAB Data
AATL Data
3D 2D
An Addendum to Tamrielic Lore is an asset repository focusing on artifacts, weapons, armor, books, and other miscellaneous assets that modders can use in their mods.
Sound Data
Scripting Audio
Asset repository featuring a number of new sound effects and music tracks, already setup with in-game activators, ready to be used to add additional atmospheric and ambient tracks to various locations.
Outlander Asset Library
3D 2D
Technically not an asset repository, the Oulander Asset Library is still a free collection of assets that modders can use in their own mods, provided they add a link to the library's archive on Patreon in their documentation and Read Me files. Note, some assets might be a bit buggy, but there's still some useful resources here.
SOV Data
Exteriors 3D
A minor asset repository featuring terrain and architecture assets designed specifically for use with Sheogorad and Azura's Coast style regions, alongside more northern and colder climates.
