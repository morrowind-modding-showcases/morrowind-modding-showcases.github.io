General Tools and Utilities: Description:
Morrowind Modding Wiki - Tools Page A nearly comprehensive list of different modding tools for Morrowind, covering everything from basic external editors to name generators, mod cleaning, 3d models, and generating animated grass.
Teo's Online Construction Set A web-based editor and workspace for designing quests.
TES3CONV A tool for converting Morrowind ESP files into JSON files and vice-versa.
Morrowind Blender Plugin
Merge to Master A tool for merging ESP files into a required ESM (master) file
TESFaithSharp Plus A utility for moving, duplicating, and removing landmasses from .esp and .esm files. Typically used to make compatibility patches between landmass mods.
Morrowind Voice Generator A utility for generating mass voice files for a specific or large number of mods at once, with the ability to tag particular emotions to particular lines. Requires additional frameworks and/or voice tools for actual implementation.
PNG - DDS Texture Converter A utility for converting textures to and from PNG and DDS formats.
TES3ZEROEDIT A browser-based editor for editing mod records.
NIFZEROEDIT A browser-based NIF editor
Kezyma's Map Builder for Morrowind A tool to generate html-based maps of current load orders or specific mods.
Export Sphere Script A MWSE tool that allows the spawning and scaling of an in-game sphere that can capture anything inside it and export it into Blender.
UESP Script Function List A list of MWscript functions.
Vvardenfell Flora Location Guide A gallery showing the common regions for certain varieties of flora in Morrowind.
Morrowind Modding Community Asset List A document of open-permissions assets that other modders can use in their mods.
Morrowind Visual Index A gallery of screenshots of CS objects and references

MWSE Frameworks: Description:
Skills Module Allows creation and addition of new skills in MWSE
Magicka Expanded Allows for the creation of new spells and spell effects in MWSE
The Crafting Framework Allows for new crafting mechanics to be defined and added to the game in MWSE
Onion - Layered Accessories Framework for adding additional armor and clothing slots to be used in-game in MWSE
MWSE Perk Framework Framework for adding functional perks to the game in MWSE
The Achievement Framework Allows for defining conditions and enabling in-game achievements, complete with new UI features, in MWSE.
Tatau - The Tattoo Framework Framework for adding body modification options in-game with MWSE
Bazaar - The Trading Framework Framework for adding and defining new currencies and bartering options in MWSE
Smith - The Weapon Crafting Framework Framework for breaking weapons down into parts and re-combining them into new weapons in MWSE
Beware the Night Resource for creating unique day and night-time leveled lists for exterior cells in MWSE.
Merlord's Character Backgrounds Expands the CharGen process with new character background options. Can be used as a framework to add additional background presets for MWSE.
MWSE Dynamic Object Replacer Framework for replacing objects at runtime for MWSE.
FluadHTN - The AI Framework (formerly OdaiHTN) Framework for setting up AI behaviors. Works for both MWSE and OpenMW
Set Bonus Framework that adds bonuses for matching sets, with modder resource interop support for other mods to define their own sets for both MWSE and OpenMW
Quick Select Menu A Framework for designing quick select menus for your own mods using MWSE
MUSE 2 - Morrowind Music System Extended Framework for defining location or region based playlists or soundtracks using MWSE
HeartStrings Music Framework with modder features for defining location and region based playlists or soundtracks (similar to MUSE) for MWSE
Dynamic Conversations (MWSE) A framework to add procedural voiced and/or text conversations to random NPCs in set locations, or specific NPCs at different times of day or weather conditions, with animation support for MWSE.
Kezyma's Voices of Vvardenfell A framework to add voiced dialogue to in-game dialogue text boxes, works for both MWSE and OpenMW.
OpenMW Frameworks: Description:
OMW Achievements OpenMW conversion of the MWSE Achievement Framework, allowing modders to enable, define, and set new in-game achievements for players to unlock with OpenMW
(OpenMW) Crafting Framework Allows for the creation of new crafting mechanics in OpenMW with mod-support for defining new recipes for craftable items
Stats Window Extender (OpenMW) Framework and API that allows modders to extend the UI and Stats Window with new sections and display new information with OpenMW
Skill Framework (OpenMW) Framework that allows modders to define and add new types of skills to the game using OpenMW
S3maphore - OpenMW Music Management from the Future Framework for defining custom music playlists for set times or locations for OpenMW
Character Traits Framework (OpenMW) A Framework based on Merlord's Character Backgrounds that allows modders to define new character generation elements for OpenMW
SPELL FRAMEWORK PLUS (OpenMW) A framework for adding custom spell effects to the game using OpenMW lua
Perk Framework (OpenMW) A framework for adding new perks to the game for OpenMW.
Dynamic NPC Framework (Procedural Chatter) A framework for adding new procedural voiced and/or text conversations between NPCs, as well as NPC scheduling, companionships, and animations for OpenMW.
Magic Window Extender (OpenMW) Includes support for added spell effects and icons in the Magic window of the UI.
FlexTag - The Tagging Framework That HOLDS A framework for querying and adding tags, useful for lua mods.
H3lp Yours3lf - OpenMW Helper Interfaces
OpenMW Lua Helper Utility
darkelfmodding.com — Morrowind modding, showcased since 2014
